为什么需要它

电商详情页的图片，本来就不该让你一张张右键另存。

图片散落各处

主图、缩略图、详情长图分散在不同区块，还常常是懒加载，翻半天也找不全。

无法批量保存

浏览器原生只能一张一张另存，遇到几十张详情图，光是点右键就要花掉十几分钟。

格式不统一

同一个页面里 jpg、webp、png 混着来，做素材整理时还得再转一遍格式。

核心功能

六个能力，覆盖从提取到保存的全过程。

一键提取

扫描页面全部商品图，兼容 srcset、data-src 等懒加载写法与背景图。

智能过滤

自动排除图标、LOGO、占位图与 1×1 像素，小于 100×100 的图片不会混进结果。

集中预览

在新标签页里以网格展示所有提取到的图片，附尺寸信息与来源标注。

自由勾选

支持全选、反选、清空选择，也可以按尺寸筛选后再挑，已选数量实时显示。

统一 PNG

jpg / webp / png 一律经 canvas 转码为 PNG，素材格式整齐划一。

批量下载

一键保存到浏览器默认下载目录，文件名自动编号为 商品图_001.png。

安装步骤

四步完成，全程不需要命令行。

  1. 1

    下载并解压

    下载插件压缩包，解压到本地任意文件夹（路径建议用纯英文，避免个别环境兼容问题）。

  2. 2

    打开扩展管理页

    在浏览器地址栏输入 chrome://extensions 或 edge://extensions 后回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选中第 1 步解压出来的文件夹即可。

使用方法

打开任意商品详情页，右下角会出现蓝色「获取图片」按钮；点击后自动跳转到图片展示页，勾选需要的图片，点「下载选中」即可。
